# Архитектура danikk_space_engine

Документация разделена по подсистемам. Заголовки, на которые ссылаются разделы, указаны относительно `include/danikk_space_engine/`; исходники — относительно `source/`.

## Подсистемы

- [Runtime](runtime.md) — запуск, кадр и порядок обновления.
- [World](world.md) — `World`, хранилища ресурсов, чанки и геометрия.
- [Planet](planet.md) — генерация и обновление планетарного ландшафта.
- [Components](components.md) — компоненты точек, связей и тел мира.
- [Tools and editing](tools.md) — выбор инструментов, выделение и изменение геометрии.
- [Rendering](rendering.md) — меши, материалы, ассеты и подсветка.
- [Assets](assets.md) — загрузка статических ресурсов и каталог материалов.
- [Items](items.md) — типы поведения предметов, определения предметов и инвентарные слоты.
- [Math](math.md) — лучи, шум и интерполяция.
- [GUI and localization](gui.md) — отладочная панель и локализация.
- [Profiling](profiling.md) — сбор и вывод времени CPU.
- [Scenario](scenario.md) — начальная сцена.
- [Shapes](shapes.md) — legacy-заготовки форм и коллизий.

## Основной поток данных

```text
main::begin()
  -> загрузка ресурсов и материалов
  -> GUI и локализация
  -> World::init() -> startBaseScenario()

каждый кадр
  -> GUI::frame()
  -> World::tick() -> WorldBody/Chunk/Point component tick
  -> World::frame()
       -> WorldBody component frame (обновление планеты)
       -> приём результата ChunkLoader
       -> создание мешей и frame компонентов чанков
       -> отрисовка чанков и подсветки
```

Документы описывают текущую реализацию. Если код меняет владение ресурсом, порядок кадра или формат сохранения, обновляй соответствующий файл вместе с изменением.
