# Ассеты и материалы

## `asset.h`

- `StaticAssetCollection` — набор ресурсов, используемых приложением: базовые 2D/3D-шейдеры, шрифт, низкополигональная сфера, куб, модель MG-42 и текстуры интерфейса.
- `load()` загружает шейдеры и шрифт, настраивает их как GUI-ресурсы по умолчанию, загружает меш и текстуру контейнера.
- Глобальный экземпляр — `static_asset_collection`.

## `material.h`

- `MaterialId` — индекс материала в закрытом каталоге `material_list`.
- `MaterialDefinition` содержит имя, RGB-цвет и текстуру.
- `default_materials` задаёт ID материалов void, grass, stone, lava и water.
- `loadMaterials()` однократно создаёт стандартные записи; текстуры загружаются по именам `grass_32x32`, `stone_32x32`, `lava_32x32`, `water_32x32`.
- `getMaterialID(name)` ищет материал по имени и возвращает void при отсутствии совпадения.
- `getMaterial(id)` возвращает ссылку по индексу.

## Связи и ограничения

- `ChunkMaterialRange` хранит диапазоны индексов меша по материалу.
- `StaticAssetCollection` использует загрузчики `danikk_engine` для шейдеров, текстур, шрифтов и OBJ-мешей.
- Каталог материалов — глобальный внутренний массив; API добавления пользовательских материалов пока не предоставлен.
