# Предметы и инвентарь

## `item.h`

- `ItemTypeId` выбирает общую категорию поведения. Сейчас зарегистрированы `none` и `weapon`.
- `ItemType` содержит callbacks `use`, `equip`, `unequip` и `draw`; тип задаёт общую реализацию поведения для всех его предметов.
- `ItemDefinitionId` идентифицирует конкретное определение предмета. ID 0 зарезервирован; сейчас определён только `mg42`.
- `ItemDefinition` связывает конкретный предмет с `ItemTypeId`, именем, лимитом стопки, мешем, текстурой, цветом отображения и данными категории. Текстура хранится непосредственно в определении как ресурсный handle.
- `ItemDefinitionParameters` — tagged-by-`type_id` union числовых параметров. Для оружия предусмотрены урон, бронепробитие, калибр и скорострельность; значения MG-42 пока нулевые и требуют игровой настройки.
- Меш MG-42 и его текстурный handle хранятся непосредственно в `ItemDefinition`. `StaticAssetCollection` не содержит ассеты конкретного предмета; пока для MG-42 отдельной текстуры нет, используется белая текстура.
- `loadItemCatalog()` загружает меш MG-42 и вызывается из `StaticAssetCollection::load()`. `getItemDefinition()` и `getItemType()` проверяют ID.
- `equipItem()` и `unequipItem()` вызывают callbacks категории оружия и переключают позу рук `HumanComponent`, если на точке есть человек. Стрельба из инвентарного предмета пока не подключена.
- `drawItem()` отправляет меш в callback категории. Рендерер должен предварительно активировать нужный shader и передать мировую матрицу.

## `component/point/inventory.h`

- `InventorySlot` хранит `ItemDefinitionId`, количество, 64-битное состояние экземпляра и флаг `is_equipped`. Предметы с отличающимся состоянием должны находиться в разных слотах.
- `InventoryComponent` содержит динамический массив слотов и может быть прикреплён к любой точке, например человеку, станку или хранилищу.
- `createHumanSoldier()` создаёт человека с инвентарём из одного слота, содержащим надетый MG-42.
- Слот хранит ID определения, а не `Mesh*`; отображение и поведение разрешаются через каталог предметов.
- Лимит стопки берётся из `ItemDefinition::max_stack`; автоматическое добавление, объединение и удаление предметов пока не реализовано.
