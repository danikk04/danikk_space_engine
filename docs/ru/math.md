# Математические модули

## `math/ray.h`

- `Ray` — начало и направление луча.
- `RayTriangleIntersection` — флаг попадания, расстояние и нормаль.
- `intersectRayTriangle()` — проверяет пересечение луча с треугольником.
- `World::raycast()` использует эту функцию для геометрии чанков; сначала выполняет отсечение по ограничивающей сфере чанка.

## `math/noise.h`

Функции находятся в `danikk_space_engine::math`:

- `latticeNoise3D()` — детерминированное значение в узле целочисленной решётки.
- `valueNoise3D()` — интерполированный шум в 3D-координате.
- `fractalNoise3D()` — сумма октав шума с заданными persistence и количеством октав.

Планетарное скалярное поле использует шум для вариации радиальной поверхности и формирования пещер.

## `math/interpolation.h`

- `linearInterpolate()` — линейная интерполяция двух чисел.
- `quinticFade()` — плавная quintic-кривая для шумовой интерполяции.
- `smoothStep()` — сглаживает переход между двумя границами.

## Точность

Позиции тела мира и чанков используют `double`/`glm::dvec3`, чтобы поддерживать большие координаты. Локальные вершины чанков и GPU-геометрия используют `float`/`vec3`.
