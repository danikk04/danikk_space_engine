# Профилировщик CPU

## `profiler.h`

- `Profiler` — единственный глобальный накопитель временных данных; экземпляр `profiler` определён в `source/profiler.cpp`.
- `beginTick()` и `endTick()` обрамляют кадр. `endTick()` раз в интервал выводит иерархический отчёт.
- `Watcher(name)` измеряет длительность области через `steady_clock`; деструктор записывает время в профилировщик.
- Вложенные `Watcher` образуют дерево: например, `frame -> World::frame -> Planet -> Planet chunk set update`.
- Отчёт показывает число тиков, среднее время на тик, максимум и количество вызовов.

Профилировщик включает время вложенных операций в их родительские области. Поэтому длительности родителей и детей нельзя складывать как независимые затраты.

Профильные точки находятся в `main.cpp`, `World`, `Chunk`, планетарном компоненте и функциях удаления ресурсов.
