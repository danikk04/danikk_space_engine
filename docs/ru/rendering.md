# Отрисовка и меши

## `world/chunk.h`

- `Chunk::createMesh()` создаёт меш из видимых треугольников объёмных ячеек и поверхности.
- Для объёмных ячеек сравниваются грани по наборам ID точек; совпадающие внутренние грани не добавляются в меш.
- Для каждой вершины формируются нормаль и UV; результат загружается в `Mesh`.
- Меш лениво пересобирается в `World::frame()`, когда установлен `mesh_dirty`.
- После построения вычисляется ограничивающая сфера. `World::raycast()` пропускает чанк, если луч не пересекает её до ближайшего попадания.

## Материалы и отрисовка

`material.h` определяет `MaterialId`, `MaterialDefinition` (имя, цвет, текстура), стандартные ID и функции загрузки/доступа. `ChunkMaterialRange` группирует индексные диапазоны меша по материалам. Рисование чанка и применение шейдера выполняются в `Chunk::draw()`.

## Подсветка полигонов

`effects/polygon_highlight.h` объявляет `drawPolygonHighlight()` и `drawPolygonHighlights()`. Вызов из `World::frame()` рисует закреплённые грани и грань под курсором. Земля выбирается инструментами, но отдельная polygon highlight система предназначена для редактируемых граней построек.

## GPU и потоки

- Генератор чанков может подготовить CPU-геометрию в worker-потоке.
- Создание и обновление GPU-объектов выполняются при обработке чанка на основном потоке.
- `Chunk::destroyMesh()` освобождает GPU-ресурсы; перемещение `Chunk` передаёт владение мешем.
