# World и геометрия

## `world/world.h`

- `World` — координирует данные мира, камеру, обновление, raycast и редактирование.
- `data` — `WorldData`, владеет пулами ресурсов.
- `chunk_loader` — worker для генерации планетарных чанков.
- `tick()`, `frame()` — выполняют игровой тик и кадр отрисовки.
- `raycast(origin, direction, max_distance)` / `raycastFromCamera()` — находят ближайшую грань; результат — `RaycastHit`.
- `extrudeFaces()` / `deleteVolumeCells()` — изменяют выбранные грани объёмных ячеек.
- `getCameraWorldPosition()`, `getChunkWorldPosition()`, `getPointWorldPosition()` — преобразуют координаты камеры, чанка и точки в мировые.

## `world/data.h`

- `WorldData` приватно хранит пулы точек, объёмных ячеек, земляных треугольников, чанков, тел и слотов компонентов.
- `create...()` выделяют ресурс и возвращают ID; `get...()` возвращают ссылку на активный ресурс; `is...Active()` проверяют ID.
- `addPointReferenceToChunk()` учитывает, в скольких чанках используется точка.
- `addVolumeCellToChunk()` и `addGroundTriangleToChunk()` регистрируют ресурс в чанке и связывают его точки.
- `destroy...()` удаляют ресурсы и их связи; `clear()` освобождает содержимое пулов, `release()` также освобождает ёмкость.

## `world/resource_pool.h`

- `WorldResourcePool<T, Id>` хранит стабильные индексируемые слоты, массив активных ID, обратные индексы активного массива и список свободных ID.
- `create()` повторно использует свободный ID или добавляет слот.
- `free()` удаляет ID из активного списка заменой последним элементом и добавляет его в список свободных.
- `isActive()` проверяет активность через `active_indices`, без линейного поиска.

## `world/body.h` и `component/world_body/world_body.h`

- `WorldBody` задаёт мировую позицию и хранит ID своих чанков и компонентов тела.
- `WorldBodyComponentType` описывает функции жизненного цикла, `tick`, `frame` и приёма результата генерации.
- `WorldBodyComponentSlot` связывает компонент с телом; payload хранится inline до 32 байт либо во внешней памяти.

## `world/chunk.h`

- `Chunk` группирует ID геометрии и компонентов, задаёт локальную систему координат и владеет GPU-мешем.
- `position` — мировое смещение чанка; точки хранятся относительно него.
- `volume_cell_ids`, `ground_triangle_ids`, `point_ids` — ресурсы чанка.
- `createMesh()` строит меш и материалные диапазоны; `mesh_dirty` означает, что меш нужно обновить.
- `bounds_center`, `bounds_radius` — ограничивающая сфера готового меша; `World::raycast()` использует её для broadphase. При грязных границах чанк проверяется без отсечения.
- `tick()`, `frame()`, `draw()` обновляют компоненты, готовят рендер и рисуют меш.

## `world/volume_cell.h`, `world/ground_triangle.h`, `world/point.h`

- `Point` хранит локальную координату и `referencing_chunk_count`.
- `VolumeCell` хранит до восьми ID точек, топологию, материал, массу, температуру и здоровье. Также содержит `chunk_id` и `index_in_chunk` для прямого удаления из чанка.
- `GroundTriangle` хранит три ID точек и такие же обратные ссылки на чанк и индекс.
- `VolumeCellTopologyDefinition` задаёт точки, треугольники и грани каждой поддерживаемой топологии.
- При удалении ячейки или треугольника запись удаляется swap-remove; индекс перемещённого элемента корректируется.

## `world/face_ptr.h` и `world/chunk_loader.h`

- `FacePtr` идентифицирует грань ячейки или земляной треугольник через ID чанка и ресурса.
- `RaycastHit` содержит попадание, расстояние, позицию, нормаль, `FacePtr`, индекс треугольника и ID трёх точек.
- `ChunkLoader` хранит запросы/результаты и worker-поток. `updatePendingRequests()` обновляет очередь; `tryTakeCompleted()` возвращает готовый результат главному потоку.

## Ключевые ограничения

- ID — индексы пулов; поколения есть только у слотов компонентов тела для отбрасывания устаревших результатов генерации.
- GPU-ресурсы создаются и освобождаются на основном потоке.
- Пул владеет памятью слотов; массивы в чанке и теле содержат ID, а не копии ресурсов.
